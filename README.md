# nazli-akmali.github.io

My portfolio, served by GitHub Pages at <https://nazli-akmali.github.io/>.

Plain HTML, CSS and JavaScript. No build step.

- `index.html` – introduction and page layout (look for `EDIT:` comments)
- `projects.js` – the list of projects shown on the page
- `styles.css`, `main.js` – styling and rendering

## Adding a project

1. Turn on GitHub Pages in the project's own repo. It will be served at
   `https://nazli-akmali.github.io/<repo-name>/`.
2. Add an entry to `projects.js` with that URL in `page`.

## Preview locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```
